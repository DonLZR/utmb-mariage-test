# BROCÉLIANDE V3.4.0 — prototype Parcours « Terres de légendes »

Prototype ciblé de la section **Parcours**, construit sur la version V3.3.1/V3.3.4 fournie.

## Ce qui change
- double page intérieure de grimoire, responsive ;
- carte fictive sur parchemin, sans numéro ni texte incrusté ;
- titre exact **Terres de légendes** et toponymes arthuriens superposés en HTML ;
- cinq pastilles interactives reliées aux cinq premières étapes réelles du Google Sheet ;
- fiche d’étape et accès à la section correspondante ;
- personnalisation des positions depuis `config.js` ou via les colonnes facultatives `carte_x` / `carte_y` du Sheet ;
- textes d’interface FR / IT / ES ;
- cache PWA porté en V3.4.0.

## Ce qui ne change pas
- couverture d’accueil verrouillée ;
- autres sections et leur ordre ;
- formulaires, déblocages, galerie, dossard et Coach ;
- `Code.gs` et la connexion GitHub / Google Apps Script.

## Contenu
- `Structure_GitHub/` : version complète reconstituée pour contrôle ;
- `Structure_GitHub/assets/map/` : nouveaux visuels de carte ;
- `Apps_Script/Code.gs` : copie de référence, non modifiée ;
- `GUIDE_INSTALLATION.md` : procédure de déploiement ciblé.

`cles.js`, les icônes personnelles, l’image Coach et les médias privés du dépôt actif doivent être conservés.
